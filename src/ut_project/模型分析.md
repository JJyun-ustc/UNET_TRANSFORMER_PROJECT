# UNet-Transformer 去噪模型分析

## 1. 项目与模型概述

本项目实现的是一个面向图像去噪任务的 `UNet + Transformer` 混合模型。整体结构采用 UNet 编码器-解码器框架，在瓶颈层引入 Transformer 模块，用于增强全局上下文建模能力。当前配置中，训练默认参数为：

- `patch_size = 256`
- `batch_size = 8`
- `epochs = 12`
- `base_channels = 32`
- `embed_dim = 128`
- `num_heads = 4`
- `transformer_layers = 4`
- `ff_dim = 256`

模型的训练目标不是直接预测干净图像，而是预测噪声本身。训练流程为：

1. 从训练集读取干净图像。
2. 按指定噪声范围动态加入高斯噪声。
3. 模型输入带噪图像，输出预测噪声。
4. 使用 `MSELoss` 约束预测噪声与真实噪声的差异。
5. 推理时通过 `denoised = noisy - pred_noise` 还原去噪结果。

这种“预测噪声而非直接预测图像”的方式有两个优点：

- 目标更明确，训练更稳定。
- 对不同噪声强度更容易统一建模。

## 2. 模型结构分析

### 2.1 编码器与解码器

模型主体是一个三次下采样的 UNet：

- `stem`：初始卷积块，提取浅层特征。
- `down1/down2/down3`：逐步降低分辨率并提升通道数。
- `up1/up2/up3`：逐步恢复分辨率，并通过跳跃连接融合浅层与深层特征。

UNet 的优势在于：

- 编码器负责提取语义信息。
- 解码器负责恢复空间细节。
- 跳跃连接保留边缘、纹理、轮廓等局部信息。

这对于图像去噪非常重要，因为去噪任务既需要全局判断噪声模式，也需要保留局部真实纹理。

### 2.2 Transformer 瓶颈层

在最深层特征图上，引入了 `TransformerBottleneck`：

- 先用 `1x1 Conv` 将通道投影到 `embed_dim=128`
- 再把二维特征图展平成序列
- 使用 `4` 层 `TransformerEncoder`
- 最后再投影回卷积特征图通道数

它的主要作用是：

- 补足卷积在长距离依赖建模方面的不足
- 让图像中远距离区域之间也能建立联系
- 对大尺寸图像中的重复纹理、结构一致性、背景区域更有帮助

当前 `patch_size=256`，经过 3 次下采样后瓶颈特征图尺寸约为 `32 x 32`，即 Transformer 实际处理约 `1024` 个 token。这个规模已经明显强于较小 patch 下的上下文范围，但也带来了更高的显存和计算压力。

## 3. 实验结果整理

根据 `result.txt` 中的记录，模型分别在小噪声、中等噪声和大噪声三种设定下进行了 12 个 epoch 的训练与测试。

### 3.1 小噪声结果

训练曲线特征：

- `avg_loss` 从 `0.005711` 下降到 `0.000431`
- `avg_psnr` 在 `32.72 dB` 到 `35.36 dB` 之间波动
- 最佳 epoch 平均 PSNR 出现在第 `10` 轮，约 `35.36 dB`

测试样本结果：

- `0806.png`，噪声标准差 `0.048`，PSNR `30.23 dB`
- `0816.png`，噪声标准差 `0.027`，PSNR `35.63 dB`
- `0898.png`，噪声标准差 `0.006`，PSNR `41.62 dB`

这组结果说明：

- 模型在小噪声场景下表现最好。
- 当噪声标准差很低时，PSNR 可达到 `40 dB` 以上，说明模型对轻度噪声的恢复能力较强。
- 随着噪声接近该档位上限，PSNR 会明显下降，但总体仍保持较高水平。

三张测试样本的平均 PSNR 约为 `35.83 dB`，与训练阶段最优平均 PSNR 非常接近，说明该档位下模型已经具备较好的实用价值。

### 3.2 中等噪声结果

训练曲线特征：

- `avg_loss` 从 `0.011830` 下降到 `0.001636`
- `avg_psnr` 从 `24.16 dB` 提升到 `28.97 dB`
- 最佳 epoch 平均 PSNR 出现在第 `12` 轮，约 `28.97 dB`

测试样本结果：

- `0866.png`，噪声标准差 `0.061`，PSNR `30.44 dB`
- `0824.png`，噪声标准差 `0.109`，PSNR `28.15 dB`
- `0818.png`，噪声标准差 `0.145`，PSNR `26.15 dB`

这组结果说明：

- 模型在中等噪声场景下仍然保持了稳定收敛。
- PSNR 随噪声强度增加而下降的趋势非常明显。
- 当噪声标准差接近该档位上界时，模型已经出现一定程度的细节恢复困难。

三张测试样本的平均 PSNR 约为 `28.25 dB`。这表明模型对中等强度噪声具有较强去噪能力，但恢复质量已经明显弱于小噪声场景。

### 3.3 大噪声结果

训练曲线特征：

- `avg_loss` 从 `0.018928` 下降到 `0.003881`
- `avg_psnr` 从 `21.75 dB` 上升到峰值 `25.14 dB`
- 最优平均 PSNR出现在第 `10` 轮，之后略有回落

测试样本结果：

- `0857.png`，噪声标准差 `0.264`，PSNR `25.66 dB`
- `0895.png`，噪声标准差 `0.282`，PSNR `21.09 dB`
- `0858.png`，噪声标准差 `0.265`，PSNR `24.78 dB`

这组结果说明：

- 模型在大噪声情况下仍能学习到一定的恢复能力，但性能下降明显。
- 高噪声已经开始严重干扰细节结构恢复。
- 当噪声强度接近 `0.28` 左右时，PSNR 可能下降到 `21 dB` 左右，说明视觉质量会出现较明显退化。

三张测试样本的平均 PSNR 约为 `23.84 dB`。这说明当前模型对于大噪声场景具备基础去噪能力，但仍然存在较大提升空间。

## 4. 综合性能分析

### 4.1 优势

从整体结果看，这个模型已经具备以下优点：

- 在小噪声场景下表现较强，PSNR 可稳定达到 `34-35 dB` 左右。
- 在中等噪声场景下仍能维持 `28 dB` 左右的恢复质量，说明模型具有较好的鲁棒性。
- 即使在大噪声场景下，模型仍能学习到一定程度的有效去噪，而不是完全失效。
- UNet 的局部细节保留能力与 Transformer 的全局建模能力形成了较好的互补。

### 4.2 当前瓶颈

当前结果也暴露出几个比较明确的问题：

#### 1. 噪声越大，性能下降越明显

这是目前最直接的结论。小噪声到中噪声再到大噪声，模型平均 PSNR 呈现持续下降趋势。这说明模型虽然能适应多档噪声，但在强噪声场景下恢复能力还不够强。

#### 2. 训练后期存在波动

例如：

- 小噪声在第 10 轮达到峰值后略有回落
- 大噪声在第 10 轮后也出现回落

这表明训练并不是单调提升的，可能存在：

- 随机噪声采样带来的评估波动
- 学习率后期偏大
- 模型对高噪声数据后期收敛不够稳定



#### 3. 测试阶段的 PSNR 本身带有随机性

当前 `evaluate_psnr()` 在每个 epoch 结束时会重新随机加噪，因此不同 epoch 的 `avg_psnr` 不完全是在同一批固定噪声样本上比较。  
这意味着：

- 曲线有一定参考价值
- 但不同 epoch 的绝对数值不完全严格可比

换句话说，训练后期的小幅波动，不一定全部来自模型退化，也可能来自测试时随机噪声本身。

## 5. 可改进方向

结合当前模型结构与实验结果，建议从以下几个方向继续优化。

### 5.1 优先改进：固定验证噪声与保存标准

最优先建议不是先盲目加大模型，而是先把评估做得更稳定。

建议：

- 在验证阶段固定随机种子
- 或提前生成固定的验证噪声样本
- 将 `best_model` 的保存标准从训练 loss 改为验证集 `avg_psnr`

这样做的收益很直接：

- 训练曲线更稳定
- 不同 epoch 更容易横向比较
- 选出的 best model 更可靠

### 5.2 增加训练轮数并加入学习率调度

当前只有 `12` 个 epoch。对于一个包含 Transformer 瓶颈的图像恢复模型来说，这个训练轮数偏少，更像是一个初步实验。

建议：

- 将 epoch 提升到 `20-50`
- 引入学习率调度器，如 `CosineAnnealingLR` 或 `ReduceLROnPlateau`

这样可以：

- 让模型在后期继续细化恢复能力
- 降低训练后期指标波动
- 尤其对中噪声和大噪声场景更可能带来提升

### 5.3 针对大噪声场景增加模型表达能力

如果目标是提升中大噪声效果，可以考虑：

- 适度增大 `embed_dim`
- 适度增大 `ff_dim`
- 适度提高 `base_channels`
- 或继续增加 Transformer 层数

不过这类改动要谨慎，因为：

- 计算量和显存压力会明显增加
- 数据量只有 800 张，模型过大可能过拟合

更稳妥的策略是：

1. 先保持当前 `4` 层 Transformer
2. 优先延长训练、加调度器、稳定评估
3. 如果仍不足，再考虑增大模型

### 5.4 优化数据采样策略

当前训练采用随机裁剪 patch 的方式，适合显存受限场景，但也存在两个问题：

- 每个 epoch 每张图只提供有限局部区域
- 大尺寸图像中的全局结构未被充分覆盖

建议尝试：

- 同一张图每轮采多个 patch
- 使用更系统的 patch 覆盖策略
- 或构建更大的训练迭代数来覆盖更多区域

这样做可能尤其有助于：

- 提升中大噪声下的细节恢复稳定性
- 提高大尺寸图像上的泛化能力

### 5.5 引入更符合视觉质量的损失函数

当前只使用了 `MSELoss`。它简单有效，但偏向像素平均误差，容易导致图像偏平滑。

后续可以尝试组合损失：

- `L1 Loss`
- `MSE + L1`
- 感知损失 `Perceptual Loss`
- SSIM 或 MS-SSIM 相关损失

这些损失在图像恢复任务中常常能带来：

- 更自然的纹理恢复
- 更好的视觉观感
- 在高噪声场景下更稳的细节保留

### 5.6 训练多噪声统一模型

当前实验是分小、中、大三档噪声强度分别训练。这个做法便于分析，但实际使用中可能还需要一个统一模型。

后续可以尝试：

- 直接使用更宽的随机噪声区间统一训练
- 或加入噪声强度作为条件输入

这样可以使模型：

- 在不同噪声水平下更灵活
- 减少维护多套权重的成本

## 6. 结论

从当前结果来看，这个 `UNet + Transformer` 去噪模型已经具备较好的基础性能：

- 小噪声场景表现优秀
- 中噪声场景表现稳定
- 大噪声场景仍有可用性，但恢复质量明显下降

模型设计上，UNet 提供了有效的局部细节恢复能力，Transformer 瓶颈增强了全局上下文建模，这一组合在当前实验中是有效的。

如果后续要继续提升模型，建议优先级如下：

1. 固定验证噪声并改为按验证 PSNR 保存 best model
2. 增加训练轮数并加入学习率调度
3. 优化 patch 采样策略
4. 在显存允许的前提下再考虑继续增大模型
5. 尝试更适合视觉恢复的组合损失

当前模型已经完成了从“可运行”到“有明确效果”的阶段，下一步的重点不应该只是继续堆模型规模，而应该先把评估方式、训练稳定性和数据采样策略打磨得更扎实。这些改进更有机会带来稳定且可解释的性能提升。
